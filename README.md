# Smart auto watering — автоматический полив для теплиц

Открытая система точного полива теплиц на базе ESP32: полив по фактической влажности корневого слоя, 5 независимых зон мониторинга, дистанционное управление и журнал через MQTT + Home Assistant. Проект команды конкурса «Будущее Первых» (трек «Открытия Будущего», направление «экология, сельское хозяйство и природный мониторинг»).

## Возможности
- Полив по фактической влажности почвы: пороговые уставки для каждой из 5 зон, без полива «по расписанию».
- 3 независимых канала управления насосами 12 В (реле PCA9555).
- Мониторинг: влажность почвы ×5, температура DS18B20 ×3, DHT11 (воздух), BMP280 (давление); период опроса 5 с.
- MQTT-брокер + Home Assistant: дашборд, дистанционное управление, журналирование, автоматизации.
- Автономная логика: при потере Wi-Fi контроллер продолжает полив по локальным порогам.
- Корпус: 3D-печать (PLA), каркас из фанеры (ЧПУ).

## Компоненты
| Узел | Состав |
|---|---|
| Контроллер | ESP32 (Wi-Fi, MQTT-клиент) |
| Влажность почвы | 5 аналоговых датчиков (зоны) |
| Температура | DS18B20 ×3 (1-Wire), DHT11 |
| Давление | BMP280 |
| Исполнительное устройство | PCA9555, 8-канальный модуль реле → 3 насоса 12 В |
| Питание | понижающий модуль (12 В / 5 В / 3.3 В) |

## Структура репозитория
- `Arduino/` — прошивка ESP32 (опрос датчиков, пороги зон, MQTT, управление реле);
- `Home Assistant/` — конфигурация интеграции и автоматизаций;
- `scheme/` — схема электрическая принципиальная (`Schematic_poliv_scheme_2026-02-28.png`);
- `docs/` — фотографии прототипа.

## Быстрый старт
1. Соберите систему по схеме из папки `scheme/`.
2. Прошейте ESP32 кодом из `Arduino/` (Arduino IDE / PlatformIO), укажите данные Wi-Fi и MQTT-брокера.
3. Настройте MQTT-брокер и импортируйте конфигурацию из `Home Assistant/`.
4. Откалибруйте пороги влажности по зонам под свой грунт.
